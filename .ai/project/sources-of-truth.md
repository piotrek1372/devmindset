# Sources of truth

| Question | Inspect first |
| --- | --- |
| What does a published article say, and where is it? | Live `devmindset.dev` page and URL |
| What code is supplied for an article? | Current `devmindset-examples` tree and file contents |
| How does the project describe itself publicly? | This repository's root `README.md` |
| What working rules have been recorded? | This `.ai/` tree, subject to owner review |
| Does code work? | Run the example and relevant checks in a suitable environment |
| How is WordPress configured or deployed? | Authorized CMS/ops source; currently `UNKNOWN` |

If sources conflict, record the precise discrepancy and source revision/date. Do not silently rewrite published claims or assume memory is evidence of runtime behavior. The examples README's “production-oriented” wording is a stated aspiration, not proof of a verification gate.
