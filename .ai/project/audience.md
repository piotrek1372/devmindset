# Audience

`FACT` The public README addresses readers interested in Linux internals, systems programming, and engineering reasoning. Its wording says “No tutorials. No hand-holding.”

`PROVISIONAL` Write for a technically curious reader who can follow code and wants a causal model. Define necessary concepts and show evidence, but do not substitute a command recipe for explanation. Runnable examples are experiments to observe a mechanism.

`UNKNOWN` Formal personas, assumed skill floor, priority of beginner search traffic, and whether old posts represent the desired current voice. Obtain an owner decision before encoding these as hard rules.
