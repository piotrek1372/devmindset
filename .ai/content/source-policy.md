# Source policy

`PROVISIONAL` For technical claims, prefer primary sources: upstream kernel documentation/source where applicable, man pages and official tool or language documentation. Cite the exact version or environment for behavior that varies. Verify commands and claims against those sources and a local run when feasible. A benchmark is evidence only for its disclosed workload and conditions.

Record a source URL or precise reference alongside nontrivial assertions in the working draft. Mark an unverified claim explicitly, and resolve it before publication. Do not convert a teaching analogy into a kernel or API guarantee.

`UNKNOWN` Owner-approved source hierarchy, citation format, and requirements for external expert or secondary sources.
